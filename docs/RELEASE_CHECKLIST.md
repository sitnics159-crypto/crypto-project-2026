- **Kraken — требуется предварительное разрешение.** В [уведомлении об использовании API](https://docs-legacy.kraken.com/api/docs/guides/global-intro/#notices) Kraken указывает, что коммерческое использование данных публичных API требует предварительного согласования. Через [официальную форму Blockscout](https://eaas.blockscout.com/#contact) запрошено, какой API и тариф подходят для коммерческого показа истории, меток риска и выгрузки переводов ERC-20 в CSV, включая лимиты и требования к указанию источника.
- **Решение для выпуска.** Если разрешение Kraken не получено к дате выпуска, исключить котировки, графики и USD-оценку комиссии из коммерческой версии. Если условия Blockscout для поиска и показа данных остаются неясными, отложить коммерческий выпуск этих функций до подтверждения подходящего источника. Допустимость CSV оценить отдельно.
