### Оценка нагрузки на API

Проверено по коду на [`07d2449`](https://github.com/sitnics159-crypto/crypto-project-2026/blob/07d2449f7c5e0f2a4c6f4f1783d7309e3f47a67c/index.html). Считайте обращения браузера к API, а тарифицируемые единицы и окно лимита уточняйте у поставщика.

| Действие | Запросы |
| --- | --- |
| Поиск транзакции | 1 к Blockscout |
| Поиск адреса | 3 параллельных к Blockscout |
| Смена фильтра ERC-20 или загрузка следующей страницы с сервера | 1 к Blockscout за действие. Показ дополнительных уже загруженных строк отдельного запроса не требует. |
| Отображение переводов ERC-20 и экспорт CSV | Дополнительные запросы к Blockscout возможны, если в ответе нет точности токена. Запросы для одного контракта в одной вкладке переиспользуются, а временные ошибки могут вызвать повторный запрос. CSV формируется в браузере. |
| Открытие страницы с рыночной сводкой или ручное обновление | 3 параллельных к Kraken. Резервная версия не обращается к Kraken. |

Пример расчёта для одного периода: 1 000 открытий страницы, 300 поисков адреса, 200 поисков транзакции, 100 смен фильтра, 50 серверных страниц и 100 ручных обновлений дают 1 250 базовых запросов к Blockscout плюс запросы за метаданными и 3 300 запросов к Kraken. Это сценарий для обсуждения тарифа. Перед запуском подставьте ожидаемые объёмы, оцените параллельные запросы при пике и сверяйте их с опубликованными или договорными лимитами.
