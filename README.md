# Crypto Project 2026

Статический прототип для проверки публичных транзакций тестовой сети Ethereum Sepolia.

## Возможности

- Проверка формата хеша транзакции.
- Получение доступных сведений из Blockscout Sepolia: статус, отправитель, получатель, сумма ETH, комиссия, блок и время включения.
- Краткое пояснение на основе полученных полей.
- Ссылка на запись транзакции в обозревателе Blockscout.

Если поле отсутствует в ответе API, интерфейс сообщает об этом, а не подставляет предполагаемое значение.

## Источник данных

- [Blockscout Sepolia API](https://docs.blockscout.com/devs/apis) — публичные сведения о транзакциях тестовой сети Sepolia.

Источник может временно ограничивать частоту запросов или быть недоступен.

## Ограничения и безопасность

- Прототип работает только с публичными данными Ethereum Sepolia.
- Тестовый ETH не имеет стоимости ETH основной сети.
- Сайт не подключает кошелёк, не отправляет транзакции, не принимает приватные ключи или seed-фразы.
- Пояснение строится по правилам на основе данных Blockscout; генеративная AI-модель не используется.
- Прототип не выполняет аудит смарт-контрактов и не устанавливает намерения участников транзакции.

## Запуск локально

Это статический сайт без сборки и установки зависимостей. Запустите HTTP-сервер из корня репозитория:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для проверки транзакций нужен доступ к публичному API Blockscout.

## Публикация

Основной сайт публикуется из ветки `main`. Эта ветка является отдельной разработческой версией и не должна запускать публикацию GitHub Pages.
