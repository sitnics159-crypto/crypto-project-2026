# Crypto Project 2026

Статический прототип для изучения публичных данных Ethereum Sepolia и справочных котировок BTC/ETH.

**Сайт:** [sitnics159-crypto.github.io/crypto-project-2026](https://sitnics159-crypto.github.io/crypto-project-2026/)

## Статус проекта

Работающий прототип доступен для проверки. Коммерческий выпуск зависит от согласования условий использования данных и выполнения [чек-листа выпуска](docs/RELEASE_CHECKLIST.md).

- [Проверки и публикации на GitHub Actions](https://github.com/sitnics159-crypto/crypto-project-2026/actions) показывают результаты проверки страницы, тестов на подготовленных данных и браузерных проверок с реальными API.
- [Политика безопасности](SECURITY.md) описывает порядок передачи сообщений об уязвимостях.

## Возможности

- **Проверка транзакции Sepolia:** статус, участники, тип операции, сумма ETH, комиссия, блок, время и доступные события переводов токенов. Краткое пояснение строится по полученным полям, без генеративной модели.
- **Проверка адреса Sepolia:** баланс тестового ETH, тип адреса, метки Blockscout и недавняя история транзакций с подгрузкой следующих страниц.
- **Балансы ERC-20:** после поиска адреса нажмите «Загрузить балансы». Запрос идёт в публичный API Blockscout Sepolia. Суммы отображаются с исходной точностью, а при ошибке можно повторить загрузку.
- **Переводы ERC-20:** входящие и исходящие фильтры, постраничная загрузка и экспорт загруженных записей в CSV.
- **Метки риска:** предупреждения показываются, если Blockscout явно пометил адрес как потенциально мошеннический. Такая метка не доказывает мошенничество, а отсутствие метки не подтверждает безопасность.
- **Рыночная сводка:** котировки BTC/USD и ETH/USD, изменение примерно за последние 24 часа и часовые графики. Изменение рассчитывается относительно первой доступной часовой свечи в запрошенном 24-часовом интервале; если свечи недоступны, показатель не подменяется изменением с начала календарного дня.
- **Ссылки на поиск:** результаты можно открыть по URL с параметром `tx` или `address`.

## Источники данных

- [Документация API Blockscout](https://docs.blockscout.com/devs/apis) и экземпляр Sepolia — транзакции, адреса, балансы и события токенов.
- [Kraken ticker API](https://docs.kraken.com/api-reference/market-data/get-ticker-information/) и [OHLC API](https://docs.kraken.com/api-reference/market-data/get-ohlc-data/) — котировки и часовые рыночные свечи.

Рыночные котировки являются отдельной справочной функцией и не относятся к данным блокчейна Sepolia. Сайт обращается к публичным API из браузера. Источники могут временно ограничивать частоту запросов или быть недоступны.

## Поисковые данные и ссылки

Браузер отправляет введённый публичный хеш или адрес в Blockscout Sepolia и сохраняет его в URL страницы. Если поделиться ссылкой, получатель увидит этот идентификатор. Сайт задаёт политику `no-referrer`, чтобы браузер опускал URL страницы в заголовке исходящих запросов. Запросы котировок к Kraken выполняются отдельно и не содержат поискового хеша или адреса. CSV формируется в браузере из загруженных переводов.

## Ограничения и безопасность

- Данные адресов и транзакций относятся к тестовой сети Sepolia; тестовый ETH не имеет стоимости основной сети.
- Котировки Kraken справочные, могут отличаться от других площадок и не являются инвестиционной рекомендацией.
- Сайт не подключает кошелёк, не отправляет транзакции, не принимает приватные ключи или seed-фразы.
- Пояснение транзакции основано на данных обозревателя и не устанавливает намерения участников или полный смысл взаимодействия со смарт-контрактом.
- Метки риска отражают данные Blockscout и не являются самостоятельным доказательством мошенничества или безопасности.

## Запуск локально

Это статический сайт без сборки и установки зависимостей. Запустите любой локальный HTTP-сервер из корня репозитория, например:

```sh
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Для работы функций нужен доступ к публичным API Blockscout и Kraken.

## Публикация

GitHub Actions публикует сайт в GitHub Pages только из ветки `main`. Workflow также можно запустить вручную из `main`; запуск из других веток не выполняет публикацию.

После публикации откройте [пример адреса Sepolia](https://sitnics159-crypto.github.io/crypto-project-2026/?address=0xd482cCc8EC97e9cA7a365F2403bf7f228aD149A0), нажмите «Загрузить балансы» и убедитесь, что появилась строка `FAUCET` с адресом контракта и суммой. Баланс тестового адреса может меняться.
